# Known-failure registry for the fvm suite.
#
# Every test case listed here is known to fail because the solver deviates
# from the contract the test states. Such a CTest row runs through
# cmake/expect_failure.cmake, which inverts the outcome: it passes while the
# defect is open, and it turns RED as soon as the solver is fixed - that is
# the signal to remove the entry.
#
#   ctest --test-dir build-tests -L known-broken -V
#
# A name that does not match any test case fails the build.

# The accuracy target of the lid-driven cavity: the centreline profile must
# agree with Ghia's published Re = 400 table to within a few percent. The
# cavity is converged (the profile changes by 4e-4 between 400 and 800
# iterations), so the remaining 6.9% max / 3.2% L2 error is the scheme's, and
# closing it needs a better scheme (or a finer mesh), not more iterations.
slow.cavity_msh.re400_accuracy_target

# An open channel must reach a divergence-free steady state. It does not: the
# interior divergence reaches 0.97 (the criterion is 3.7e-4) and the inlet and
# outlet fluxes are 2% apart.
#
# It is not a transient: the divergence is IDENTICAL after 600 and 1200
# iterations (0.969333 both), so the state has converged onto a mass balance
# that is wrong.
#
# The fingerprint localises the defect: the divergence is largest exactly where
# the predictor is divergent - it rises from 0.10 at the inlet to 0.47 over the
# first four columns, decays to 0.05 in the middle, and spikes to 0.97 at the
# pressure outlet. Everywhere else it is small. So the pressure correction
# leaves the predictor's divergence essentially uncancelled wherever it is
# non-zero, which is the signature of the pressure operator and the correction's
# gradient not being the same operator (see
# tests/cfd/known_failures.txt).
fvm.channel.open_outlet_divergence
