# Known-failure registry for the CFD fundamentals suite.
#
# Every test case listed here is known to fail because the solver deviates
# from the contract the test states. Such a CTest row runs through
# cmake/expect_failure.cmake, which inverts the outcome: it passes while the
# defect is open, and it turns RED as soon as the solver is fixed - that is
# the signal to remove the entry.
#
#   ctest --test-dir build-tests -L known-broken -V
#
# lists the outstanding work with the real diagnostic of every defect.
#
# A name that does not match any test case fails the build, so the registry
# cannot silently rot.

# --- Gradient ----------------------------------------------------------------
# (fixed: the cell-based Green-Gauss uses the exact face interpolation, the
#  node-based Green-Gauss reconstructs the nodes of a structured mesh from the
#  grid, and the wall ghost no longer dilutes a prescribed cell's gradient)

# --- Divergence --------------------------------------------------------------
# (fixed: the face velocity now follows the momentum assembly - a cell with a
#  prescribed velocity owns the whole face it shares with a neighbour - the
#  boundary condition is an explicit input, the mask is validated, and
#  maxDivergence() measures the same quantity as the residual)

# --- Convection --------------------------------------------------------------
# (fixed: the three entry points share one implementation, the face velocity
#  follows the momentum assembly - a cell with a prescribed velocity owns the
#  whole face it shares with a neighbour - and second order upwind rejects a
#  call without the cell gradient instead of degrading to plain upwind)

# --- Poisson / Laplacian -----------------------------------------------------
# (fixed: a Dirichlet mask that does not cover every cell is rejected instead
#  of being read out of bounds)

# --- Pressure correction -----------------------------------------------------
# (fixed: a cell without a pressure equation is excluded from the unknowns and
#  reported, instead of being silently pinned to p' = 0)

# --- Boundary conditions -----------------------------------------------------
# (fixed: a cell that owns a face-conditioned face is no longer frozen by the
#  cell mask, so a moving wall prescribed on its faces drives the momentum
#  equation instead of being silently ignored)

# --- Pressure / velocity coupling -------------------------------------------
# The pressure correction makes the divergence worse instead of removing it.
#
# Measured, with a COMPATIBLE (zero-mean) divergence source: the correction
# removes only 44% of the divergence - 1.0 before, 0.56 after - and the error
# GROWS with refinement (0.56 -> 1.52 -> 3.46 for 8x8 -> 16x16 -> 32x32).
# Refining the mesh makes the mass balance worse, which is the worst kind of
# defect.
#
# The cause is NOT the interior operator: on a field with a known value
# (p = x^2) the pressure matrix and the gradient the velocity correction
# applies both give the exact Laplacian (2.0) in the deep interior, with a
# ratio of 1.0 - see cfd.pressure.operator_consistency_on_a_known_field.
#
# The mismatch is entirely at the BOUNDARY: the cells next to a wall and the
# pinned cells (the reference cell and the pressure outlet). Those are exactly
# where the open channel shows its error (0.47 in the entry region, 0.97 at the
# pressure outlet).
cfd.pressure.correction_removes_divergence

# The pressure matrix and the gradient the velocity correction applies must be
# the same operator. They agree in the deep interior, but not next to the
# walls and the pinned cells, so the ratio is 2.12.
cfd.pressure.operator_consistency

# The coupling error must shrink with the mesh spacing. It does not: it grows
# like 1/h for a kinked source and like 1/h for a smooth one as well.
cfd.pressure.coupling_error_scaling
