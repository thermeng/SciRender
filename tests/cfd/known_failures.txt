# Known-failure registry for the CFD fundamentals suite.
#
# Every test case listed here is known to fail because the solver deviates
# from the contract the test states. Such a CTest row runs through
# cmake/expect_failure.cmake, which inverts the outcome: it passes while the
# defect is open, and it turns RED as soon as the solver is fixed - that is
# the signal to remove the entry.
#
#   ctest --test-dir build-tests -L known-broken -V
#
# lists the outstanding work with the real diagnostic of every defect.
#
# A name that does not match any test case fails the build, so the registry
# cannot silently rot.

# --- Pressure / velocity coupling -------------------------------------------
# The pressure correction makes the divergence worse instead of removing it.
#
# Measured with a COMPATIBLE (zero-mean) divergence source: the correction
# removes only part of the divergence, and the error GROWS with refinement
# (0.56 -> 1.52 -> 3.46 for 8x8 -> 16x16 -> 32x32). Refining the mesh makes
# the mass balance worse, which is the worst kind of defect.
#
# The cause is NOT the choice of gradient: the Green-Gauss and the
# least-squares gradient give the SAME ratio (2.12 / 4.05 / 7.91), so they
# agree with each other. They disagree with the pressure MATRIX, which
# assembles the distance-weighted (5-point) Laplacian: the gradient smooths a
# local feature of p' over one cell, the matrix differentiates it, and the two
# differ by O(1/h) at such a feature.
#
# The feature is the dip the pinned reference cell forces into p' (and, in the
# test, the kink of the source). The per-face decomposition in
# cfd.pressure.coupling_diagnosis shows it: the correction removes the
# divergence in total but not face by face.
#
# Part of this has been fixed: the reference cell is no longer pinned when the
# pressure system is not singular (an open boundary carries a Dirichlet cell),
# and the pinned cell of a pure Neumann domain is now chosen as the cell with
# the SMALLEST uncorrectable imbalance instead of the cell closest to the
# centroid. The numbers above are for the PURE NEUMANN case, which still needs
# a reference cell: its row is replaced by an identity row, so that ONE cell
# keeps its predictor's imbalance for the whole run and the p' field carries a
# local feature there.
#
# The remaining fix is to make the pressure matrix the divergence of the SAME
# gradient the correction applies - the pressure equation then has to be
# assembled as the composition (a wider stencil) - and to give the momentum
# operator the same gradient for its pressure term, so that the three agree.
cfd.pressure.correction_removes_divergence

# The pressure matrix and the gradient the velocity correction applies must be
# the same operator. They are not: the ratio between the matrix's row (divided
# by the cell volume) and the divergence of that gradient is 2.12 and grows
# like 1/h.
cfd.pressure.operator_consistency

# The coupling error must shrink with the mesh spacing. It does not: it grows
# like 1/h for a kinked source and for a smooth one as well.
cfd.pressure.coupling_error_scaling
